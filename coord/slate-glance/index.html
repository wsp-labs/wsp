Part 2: the stat row and the facts line under 480 px

Both renderers read the row's own width, not the window's: Electron by container queries on the stat card, GPUI by the width its row was laid out at last frame. Under 480 px two or four tiles stand two a row; three stand one line a tile: the label over its window at the left, the figure and its ring at the right. A label and a window stay on one line, cut, with the whole words on hover. The ring sits beside the figure. Every row goes across only from the width that holds its widest tile (480 px for three at the least, 544 for four, in 64 px steps to 736), and the figure steps down from 26 to 20 to 16 px where the widest would not fit a tile two a row in the 400 px panel, so no figure is squeezed or overlaps its ring.

Three tiles: one line a tile is the default, because the three stay equal and each label gets the row less its figure rather than half the row. Two a row with the third spanning is below for the owner to rule; the harness draws it with &three=pairs, the GPUI shots with the -pairs states.

Facts on a line: under 480 px one pair a line, the labels a column of their own up to 40% of the row, so the values start at one edge.

9. The catalog index as agents now read it

1,469 tokens; with the look rule below as rule 13, 1,495 of 1,500.

Depends on #2065, not built: "After a write or a large change, call slate_look and read the picture the person sees before you reply." It stays out of the index until wsp slate look lands; its mock is coord/slate-frame/index.html.

A slate is the person's visual companion beside the chat, what they glance at while you work. Not a record, a log or a second reply: words stay in the chat, and your reply never restates the slate.
Pieces, visual first (! required, (a|b) the only values, <items>):

chart: label! items! x value format unit tone height(small|normal|large) stack; <series label! value! tone>
diagram: value! label
timeline: label! items! name! start end state(done|running|failed|waiting) group now
treemap: label! items! name! value! group format
donut: label! items! name! value! format unit
image: src! caption

Every piece: id, when={cond}; items take when too. tone: default muted good warning bad info accent. emphasis: normal strong quiet. gap: tight normal loose. format, where a line lists none: plain tokens bytes percent usd inr duration integer fraction.
Pick by question: figures stats; done of many progress; a question decision; categories bars; time is a chart, x in ms or ISO; shares donut; sizes treemap; spans timeline; a flow is a diagram.
Sources, read only:

usage: account windows[] session week status note ...
cost: rateUsdPerHour accruedUsd
time: now today zone
git: branch head ahead behind changed ...
pr: number url state draft branch headSubject mergeable review checks[] word ...
Declarations: <value name start> <secret name> <derived name value> <run name cmd env args stdin on timeout every always once confirm then tool resource description> <file name> <when change={$path} or done={$run} do={steps}>
Steps: set toggle start cancel send steer queue fill open copy pane. Functions: slate_catalog functions; ago(t) "30s ago", until(t) "in 4m".
After |: where sortBy take count and more. $run reads state exit out err json; a secret only .set .len.
Rules:
1. One <slate>, one root piece, declarations beside it. Give an id to a piece you will change.
2. prop="text" is literal; prop={formula} reads live data or $values with operators, a ? b : c, [lists], {records} and functions, never methods or =>. A text child with {holes} fills a sentence.
3. Props are meaning, never style. held is a sentence that disables: bind it to a condition; "" or false enables.
4. A list binds to items; item and index read the row.
5. A press reaches you only through send("literal text", $path); <when> chains run without you.
6. Small edit: patch by id, <props id="price" value={$spot.json.v} />; bigger: resend the whole slate with if_version.
7. At a glance: at most 4 sections open, the rest collapsible open={false}; 1 table of 4 columns; notes, cells to 12 words, texts to 30; no logs, drawn tables. Replace a section, never add one beside it.
8. Fill pieces, not layout: no card in a card, never ·, • or | between things, short labels, no emoji. Heads in sentence case, never bold text.
9. Every live number says its window and unit. Show a run's json fields, never its raw out; times through date(), time() or ago().
10. Use the slate tools, never wsp from a shell.
11. A secret the person types goes in a <secret> input, never a file or the chat. One in a file stays there for the run to read, never you.
12. A button asked for where the project has no UI goes here: the slate is its UI, and the reply says so.
