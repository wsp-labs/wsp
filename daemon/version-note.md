Process rows carry the power a Mac's process drew in milliwatts, the thread that owns them and what they are, and each process frame says what its tick cost the daemon in cpu, the ps it ran included, and held rows; a process watch narrowed to a cgroup reads every cgroup under it, and proc.list reads every process itself while that watch is narrowed; a row's owner can name a warm agent's thread.
sys.history at a step under a minute answers the last fifteen minutes of reads as they were taken, sys.unwatch ends a socket's readings watch, a sys.unwatch or proc.unwatch sent before its watch is answered still ends it, and a Linux computer's own disk is read as df reads it, without running df.
proc.list answers every process at once for a reader that wants no stream: the rows a running process watch last read, or one scan of its own with cpu at 0 where none runs.
proc.scopes names each thread's roots, and every proc.watch row carries its group, its owner by the ladder (root, fork, group, the WSP_THREAD mark, cgroup, folder, coalition) and, where the daemon knows it by fact, its kind (agent, slate or tool, of the eleven words the page shares; a slate's run the host did not start reads slate off SLATE_DIR beside its WSP_THREAD), and says so when the thread is a warm agent's that no send has claimed; on a Mac the daemon follows every fork of a named root through kqueue from the moment the host names it, watched or not, and keys what it followed by the kernel's unique id; the folder rung reads a workspace's folder by device and inode, never through a link; a box reads its thread cgroups' members ahead of the 1,000-row cap and counts no kernel thread toward it.
proc.kill takes a mode (the pid, its group's members, or the pid and everything under it), the row's start time and its identity, and the host's lists of its own pids, the app's main process, each running turn's root and recorded agent, and the names agents run under; it signals each target through the identity it was read with, an audit token on a Mac and a pidfd on Linux, sends KILL to what TERM left after the grace, refuses a turn's root, its agent and every process between (past a recorded launcher down to the agent's binary, and for the turns its own run folder records), a kernel thread, in a thread cgroup a process run as an agent's name and what stands above it there, and on a box whose daemon is root and has cgroup v2 anything outside the thread cgroups and the daemon's own children; with an identity the start time is not checked; each proc row carries that identity as id.
