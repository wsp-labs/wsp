## Full CI repair round

The Mac full suites found one SSH regression: replacing the login PATH hid an existing Node and other commands from both the installed CLI and undo scripts. The shared toolsPathLine now prefers the recorded tools and preserves a nonempty ambient path. The unchanged real-shell leave/undo tests reproduced the failure and now pass alongside the Homebrew fallback regression.

A detached v0.3.10 checkout reproduced seven other failing cases: the guest tool list expected an unscoped contract, workspace-kind expectations omitted isolated metadata, three restart fixtures discarded their fake provider computers, and the paused-send assertion attached its rejection handler after the race. These test setups and expectations now match the shipped contract without changing runtime behavior. The agents-panel assertion now includes the intended per-agent facts. All 274 cases in the targeted round pass with one platform skip, after staging the newly built MCP binary matching 0.3.11; an old downloaded binary correctly refused that host's version.

The Linux build failed twice resolving Azure's Ubuntu mirror. CI and release now share a package-install step that replaces only that mirror with Ubuntu's official archive, leaves arm64 ports alone, and refreshes indexes with bounded retries before installing dependencies. Shell syntax passes; the next real CI run verifies package installation. Cold review found no weakening in the product or test corrections.

Additional host-area note candidate: prepend recorded tool paths without hiding the current login's commands; installation, undo and the installed CLI read the same PATH rule.

The next runner exposed an indirect source, mirror+file:/etc/apt/apt-mirrors.txt. Normalizing source definitions alone did not alter its Azure entry. The helper now includes that mirror-list file. A regression runs the actual shell script against temporary direct, indirect and ARM source fixtures with no sudo/network access; it failed on the Azure entry before the fix and passes afterward. All 24 mirror/workflow cases pass.

## Runner DNS diagnosis and verified repair

The archive replacement did not resolve the underlying fault: system lookups timed out for archive.ubuntu.com, security.ubuntu.com and azure.archive.ubuntu.com as both the runner and apt user, while GitHub/Microsoft resolved. Independent DNS over HTTPS returned valid Ubuntu addresses. On a disposable runner, changing only its link resolver to public DNS restored both users' lookups and both package-index requests returned HTTP 200 (diagnostic run 43051713789).

The shared installer now applies that fallback only inside GitHub Actions after a failed bounded Ubuntu lookup, discovers the default interface, flushes cached failures and rechecks before apt. A fresh runner then installed the actual musl-tools and gperf dependencies and verified both commands successfully in run 43052396205. Healthy and failed-DNS fixture cases pass, and the failed-DNS case fails against the prior helper. Cold review found no blockers. The exact test budget is updated to 149 for both runner regression cases. No product or user-computer DNS settings change.
