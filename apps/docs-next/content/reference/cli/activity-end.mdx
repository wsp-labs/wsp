# wsp activity end

{/* Written by apps/docs-next/scripts/cli.ts: change the script or its source and run pnpm --filter @wsp/docs-next generate. */}

```text
usage: wsp activity end <pid> --started <ms> [--computer <computer>]
  ends one process and everything under it, by the pid and the start wsp
  activity --json listed: TERM, then KILL after 2 s; refuses a process wsp did
  not start, an agent, which wsp stop ends, and a pid that names another process
  now

  --started     the process's start as wsp activity --json lists it, startedAt
                in epoch milliseconds; a pid that started otherwise is refused
  --computer    the computer the process runs on, which must be this one
  --json        print the raw protocol values, one JSON object per line, with
                everything else on stderr
  --state       the state file the host serves
  --host        run the line against a host on your account, by the name wsp
                hosts lists it under; WSP_HOST names one for a whole shell
```

MCP tool: [`activity_end`](/reference/mcp-tools#activityend).
